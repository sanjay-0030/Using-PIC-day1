# LED Blink using PIC16F877A

This is my Day 1 Proteus practice project.

Microcontroller: PIC16F877A  
Software Used: Proteus Design Suite  
Language: Embedded C  

Project Description:
In this project, an LED is connected to PORTB of the PIC16F877A. 
The LED blinks with a delay using a simple program.

Components Used:
- PIC16F877A
- LED
- Resistor
- Crystal Oscillator
- Power Supply
